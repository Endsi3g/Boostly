## 🚀 Installation

### Prérequis
- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0
- Firebase project configuré
- Ollama (optionnel mais recommandé)
- Google Gemini API key (fallback)

### Installation

```bash
# Cloner le repository
git clone https://github.com/Endsi3g/Boostly.git
cd Boostly

# Installer les dépendances
cd app
flutter pub get

# Lancer l'application
flutter run
```
