# ⚡ Test Rapide - BOOSTLY

## 🚀 Commandes Express

### Lancer l'Application

```powershell
cd app
flutter run
```

### Exécuter les Tests

```powershell
cd app
flutter test
```

### Analyser le Code

```powershell
cd app
flutter analyze
```

## 📋 Checklist Rapide

- [ ] `flutter pub get` exécuté
- [ ] Tests passent (`flutter test`)
- [ ] Aucune erreur (`flutter analyze`)
- [ ] Appareil/Émulateur disponible (`flutter devices`)

## 🎯 Test Minimal

1. **Lancer l'application** : `flutter run`
2. **Vérifier** : L'application démarre sans erreur
3. **Naviguer** : Tester quelques écrans
4. **Créer une tâche** : Vérifier que ça fonctionne

## ✅ Si Tout Passe

L'application est prête pour des tests plus approfondis !
