# 🤝 Guide de Contribution - BOOSTLY

Merci de votre intérêt pour contribuer à BOOSTLY !

## 📋 Comment Contribuer

### 1. Fork le Repository

1. Fork le repository sur GitHub
2. Cloner votre fork localement

```bash
git clone https://github.com/VOTRE_USERNAME/boostly-app.git
cd boostly-app
```

### 2. Créer une Branche

```bash
git checkout -b feature/ma-fonctionnalite
```

### 3. Faire des Modifications

- Écrire du code propre
- Suivre les conventions de code
- Ajouter des tests si nécessaire
- Mettre à jour la documentation

### 4. Tester

```bash
cd app
flutter test
flutter analyze
```

### 5. Commit

```bash
git add .
git commit -m "feat: Ajout de ma fonctionnalité"
```

### 6. Push et Pull Request

```bash
git push origin feature/ma-fonctionnalite
```

Puis créer une Pull Request sur GitHub.

## 📝 Conventions

### Messages de Commit

Utiliser le format conventionnel :

- `feat:` Nouvelle fonctionnalité
- `fix:` Correction de bug
- `docs:` Documentation
- `style:` Formatage
- `refactor:` Refactoring
- `test:` Tests
- `chore:` Maintenance

Exemple : `feat: Ajout de la génération de micro-tâches avec IA`

### Code Style

- Suivre les règles Flutter
- Utiliser `flutter format` avant de commit
- Respecter les règles du linter

### Tests

- Ajouter des tests pour les nouvelles fonctionnalités
- S'assurer que tous les tests passent
- Maintenir la couverture de code
